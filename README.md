# Bitcoin charts

Interactive Plotly pages for Bitcoin cycle structure, on-chain cost-basis bands, and Strategy (MSTR) treasury premium.

The [chart index](https://acken2.github.io/bitcoin-charts/) is the usual entry point. Each file is several megabytes and self-contained, so the first load can take a while.

This repository is a latest-only snapshot of those HTML files. It is not a trading system or investment advice.
